# cPIKANs

This repository contains code and results for the cPIKANs project.

## Project Structure

- `code/`: Source code
- `baselines/`: Baseline implementations
- `ablation_run_*`: Ablation study results
- `collected_results/`: Collected experimental results
- `throttle_trace.csv` and `throttle_trace.png`: data for the throttling experiment
